# CLI Hangman
Hangman game ran in the command line via ruby. I built this using OOP design principles, encasulating the logic in seperate classes (ie. saving data, playing hangman, dictionary). The game allows players to save and load games. 

## Features
- Randomly chooses a word of 5-12 characters from a list of +8000 words
- Recieve feedback on the letter locations
- Saves games
- Load games

## What I learned
I learned how to use the ruby ```File``` class including reading and writing files. I also learned to use JSON to serialize data and how to deserialize the data. I additionally learned to use pathnames, both relative and absolute, for consistency when running the game in a CLI.
